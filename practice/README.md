# Virtualmase Public Practice Index

This directory is a source-controlled record of how Virtualmase applies Autonomous Resource Management to its own public work. It is **not** a credential, customer case-study library, performance dashboard, or source of sensitive operational data.

Start with [`../docs/public-practice-model.md`](../docs/public-practice-model.md) for the evidence, review, correction, and retention rules. Then inspect the records in [`records/`](records/). Each record names its capability, property, limited decision right, source evidence, outcome, unresolved question, and public correction route.

The index contains only factual records of completed work and carefully labelled proposals. A record can demonstrate a method; it does not imply that a given pattern is universally appropriate or independently certified.
