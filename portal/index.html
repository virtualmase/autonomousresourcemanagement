02 / CONTRIBUTION PATHWAY

Work travels by record, not by rumor.

  1. 01

    Frame the work

    Name the property, reader or participant benefit, evidence/input, owner, risk, and completion condition. If the work is still open-ended, start in a Discussion.

  2. 02

    Choose a capability

    Use the capability to establish the expected artifact, quality gates, authority boundary, and receiving handoff. It organizes responsibility; it does not create permission.

  3. 03

    Open the durable record

    When the work is bounded, submit a Capability work record. Link supporting research, a prior discussion, or an accepted specification.

  4. 04

    Review, release, or return

    Submit reviewable artifacts through a pull request. Material claims, security, domain, data-retention, and property-role changes follow the published governance path.
