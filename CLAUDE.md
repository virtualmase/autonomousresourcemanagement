# ARM Session Entry Point

Read [`AGENTS.md`](AGENTS.md) first. Then read [`docs/CONTINUATION.md`](docs/CONTINUATION.md) before proposing or modifying implementation.

The repository is intentionally model-neutral. These files apply equally to human maintainers and assistants. Treat them as the durable project context; do not infer authority, deployment status, or property relationships from absent chat history.

For current flagship work, the implementation contract is [`flagship/CONTENT-ARCHITECTURE.md`](flagship/CONTENT-ARCHITECTURE.md). New public work must be portable static HTML/CSS/SVG/minimal JavaScript, original to its property, evidence-led, accessible, and safe for later owner-approved deployment.
