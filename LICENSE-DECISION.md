# License Decision Required

The project is intended to become open source, but no reuse license has yet been selected. Until a maintainer commits a `LICENSE` file, the repository remains publicly visible but ordinary copyright applies; public visibility alone is not an open-source grant.

The license choice should be made deliberately because it affects code reuse, documentation reuse, attribution, patent terms, derivative works, trademark treatment, and commercial use. The maintainer should select a license after confirming the desired approach for both software and editorial material. Consider obtaining qualified legal review before relying on the choice.
